# 03: Eigene Stellenanzeigen für Unternehmen

| Property | Value |
|--:|:--|
| *Status* | 🟢 Decided |
| *Updated* | 19 Nov 2026 |
| *Lead* | [Leonie Apel](https://github.com/mpahlkeee/Pflichtpraktikumssuche/blob/main/docs/contributors/Leonie-Apel.md) |

## Problem Statement

Die Praktikumsangebote unserer Plattform werden hauptsächlich über eine externe API bezogen. Allerdings werden nicht alle verfügbaren Praktikumsstellen über solche Schnittstellen erfasst. Insbesondere kleinere Unternehmen und Start-ups nutzen häufig alternative Recruiting-Kanäle, beispielsweise die eigene Karriereseite, soziale Netzwerke oder persönliche Netzwerke, anstatt ihre Stellenanzeigen auf großen Jobplattformen zu veröffentlichen.

Ein weiterer wichtiger Punkt ist, dass Unternehmen ihre Stellenanzeigen teilweise bewusst auf bestimmten Plattformen veröffentlichen, um gezielt Studierende und Berufseinsteiger zu erreichen.

Gerade kleinere Unternehmen und Start-ups haben häufig begrenzte Recruiting-Budgets und möchten ihre Anzeigen dort platzieren, wo sich ihre gewünschte Zielgruppe tatsächlich aufhält. Statt kostenpflichtige Anzeigen auf großen, allgemeinen Jobportalen zu schalten, nutzen sie beispielsweise:

- **Karriereplattformen für Studierende:** Hochschul-Jobportale und spezialisierte Praktikumsbörsen.
- **Hochschulnetzwerke:** Kooperationen mit Universitäten, Fachhochschulen und Career Centern.
- **LinkedIn und soziale Netzwerke:** Direkte Ansprache von Studierenden und Berufseinsteigern.
- **Eigene Karriereseiten:** Veröffentlichung von Stellenangeboten auf der Unternehmenswebsite.
- **Persönliche Netzwerke:** Empfehlungen, Kontakte zu Hochschulen oder studentische Initiativen.

Dadurch werden Stellenanzeigen nicht zwangsläufig auf großen allgemeinen Jobportalen veröffentlicht und sind möglicherweise auch nicht über unsere API abrufbar. Es besteht somit das Risiko, dass relevante Pflichtpraktika in unserer Anwendung fehlen.

## Decision

Ich habe mich dafür entschieden, Unternehmen zusätzlich zur API die Möglichkeit zu geben, eigene Praktikumsanzeigen direkt auf unserer Plattform zu veröffentlichen.

Dadurch können auch Unternehmen ihre Stellenangebote präsentieren, deren Anzeigen nicht über unsere API verfügbar sind. Besonders für kleinere Unternehmen und Start-ups bietet dies eine Möglichkeit, Studierende gezielt zu erreichen, ohne auf die Veröffentlichung auf großen Jobplattformen angewiesen zu sein.

Die Entscheidung ermöglicht eine größere Vielfalt an Praktikumsangeboten und macht unsere Plattform unabhängiger von externen Datenquellen. Gleichzeitig profitieren Studierende von einer umfangreicheren Auswahl an Pflichtpraktika in Berlin.

Die Kombination aus API und eigenständiger Veröffentlichung bietet somit eine größere Abdeckung als die Nutzung einer einzelnen Datenquelle.

## Regarded Options

| Option | Advantages | Disadvantages |
|---|---|---|
| **Nur API** | Automatisierter Import von Stellenanzeigen; geringer manueller Aufwand | Abhängigkeit von der API; nicht alle Unternehmen und Stellen werden erfasst |
| **Nur manuelle Veröffentlichung** | Unternehmen können alle relevanten Stellen direkt veröffentlichen; unabhängig von externen APIs | Höherer Aufwand durch manuelle Eingabe; Plattform muss zunächst mit Anzeigen gefüllt werden |
| **API + eigene Veröffentlichung** | Größere Angebotsvielfalt; Ergänzung fehlender Stellen; geringere Abhängigkeit von einer einzelnen Datenquelle | Zusätzlicher Entwicklungsaufwand; mögliche doppelte Stellenanzeigen |

**Begründung der Auswahl:**

Die Kombination beider Möglichkeiten bietet den größten Mehrwert. Die API ermöglicht es, bereits vorhandene Stellenanzeigen automatisiert einzubinden. Die eigenständige Veröffentlichung durch Unternehmen ergänzt dieses Angebot um Stellen, die über die API nicht verfügbar sind. So können sowohl größere Unternehmen als auch kleinere Unternehmen und Start-ups ihre Praktikumsangebote auf unserer Plattform präsentieren.
